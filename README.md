# FM 控制台

为 FM26 / FM27 制作的球队赛季数据记录与球员成长可视化工具。

玩了很多赛季以后，我希望把每一年的阵容、比赛表现、转会和年轻球员成长放到一起，留下一份能回顾、能对比的球队档案。这个工具按照我自己的游戏习惯，借助 AI 逐步制作。

## 下载与使用

前往 [最新版本下载](https://github.com/sauce8ox/FM-Console/releases/latest)，选择与你的游戏对应的 **FM26** 或 **FM27 分享版压缩包**。解压整个文件夹，双击其中的控制台 EXE 即可使用。不要只取出 EXE。

不需要自行安装 Node.js 或 Python。桌面窗口使用 Microsoft WebView2；电脑需要有可用的 WebView2 Runtime。

## 主要功能

- **赛季阵容**：整理首发、替补、租借和青训，拖动排布，支持球员 ID 查找和俱乐部批量添加。
- **赛季数据**：读取游戏存档中的比赛统计，记录转会收支、球员状态和赛季备忘录。
- **数据汇总**：查看球员在队期间的生涯合计，保留离队记录。
- **CA 追踪**：读取运行中的游戏，按月记录关注球员的能力及成长相关属性。
- **CA 走势**：比较逐月成长和相同年龄时的能力变化。

赛季记录和 CA 追踪可以独立使用，同一球员可以同时记录。读取功能只读，不修改游戏数据。游戏更新后，内存读取可能需要相应适配。

## 基本流程

新建赛季 → 添加与调整阵容 → 提交生成赛季数据名单 → 所有比赛结束后导入游戏存档中的统计。

CA 追踪按需逐月记录，写入前确认月份。详细操作见下载包内的使用说明。个人数据保存在本地，请定期另存备份；分享包不包含个人存档。
